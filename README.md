# 待读 · Bookmark Inbox

一个本地运行的 Chrome 新标签页扩展。新标签页显示书签栏直属的网页链接；把原书签移进分类文件夹，它就自然从待读列表消失。

## 安装

下载并解压本仓库，或克隆到本地：

```sh
git clone https://github.com/zhijun42/bookmark-todo.git
```

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目目录（克隆后的 `bookmark-todo` 文件夹）。
4. 打开新标签页。如果 Chrome 询问是否保留新的新标签页，选择保留。

安装不需要构建或安装 Node.js 依赖。目录包含扩展源文件，加载后请保留在当前位置。修改源文件后，可以在扩展管理页面点击此扩展的重新加载按钮。

## 使用规则

- 待读列表包含书签栏这一层的所有网页链接，包括被 `»` 溢出菜单收起的链接，按收藏时间从新到旧排列。同一时刻收藏的链接保留原书签顺序；没有收藏时间的链接排在最后。页面顶部的书签栏仍保持原生书签顺序。
- 分类文件夹及其中的所有书签不显示。「其他书签」和「移动设备书签」也不显示。
- 收藏网页时选择「书签栏」，新增的链接会自动出现。
- 阅读完成后，将原书签**移动**到分类文件夹。只在文件夹中添加一份副本，不会使原书签消失。
- 单击链接在当前标签页打开网页；`⌘` / `Ctrl` + 单击或鼠标中键沿用 Chrome 默认的新标签页打开方式。打开网页不会修改书签或完成状态。
- 页面顶部的「管理书签」可打开 Chrome 原生书签管理器。
- 页面最顶部有一条页面内书签栏，直接显示原生书签栏里的文件夹和网页。鼠标悬停文件夹约 180 毫秒会自动展开，子文件夹也支持悬停；仍可点击或通过键盘打开。右侧 `»` 收起放不下的内容，支持键盘方向键和 Escape。书签、快捷入口与按钮使用普通箭头鼠标。
- 可以把待读列表中的链接拖进顶部文件夹，也可在拖动时悬停文件夹，展开后拖入子文件夹。只有你拖放时才会移动原书签；归档后列表实时更新。
- 这条书签栏只存在于扩展的新标签页中，不会注入普通网页。Chrome 原生书签栏可设为「仅新标签页显示」；由于 Chrome 不将扩展页面视为内置新标签页，扩展页面使用上述页面内书签栏。
- 顶部提供原有的 8 个常用网站快捷入口；点击「添加快捷方式」新增，悬停入口后点击菜单可编辑或删除。快捷方式独立保存，不会进入待读列表。
- 桌面上按收藏时间从新到旧，从左到右、逐行排列为双列。每行左右两条等高；偶数条时两列等高，奇数条时左列多一条。窄窗口自动切换为单列，长标题完整换行。
- 页面没有搜索框，支持系统浅色、深色模式和键盘导航。
- 脚本书签会显示提示，需从原生书签栏运行，避免在扩展页面中执行。

## 数据与权限

使用 `bookmarks` 权限读取原生书签，以及在你拖放归档时移动原书签；用 `favicon` 权限读取 Chrome 提供的网站图标，用 `storage` 权限在本地保存快捷方式。扩展不读取浏览历史，也不会自动移动或删除书签。

页面通过书签事件更新，无须后台进程、后端、账号或远程脚本，也没有统计代码或第三方图标服务。书签是否跨设备同步，沿用 Chrome 本身的设置。

Chrome 无痕窗口不支持扩展替换新标签页。停用或移除此扩展，即可恢复原来的新标签页，原生书签保持不变。

## 验证

开发环境为 Node.js 24。运行：

```sh
npm ci
npx playwright install chromium
npm test
```

`npm test` 同时运行筛选规则测试和真实 Chromium 扩展集成测试。测试使用独立临时浏览器配置，仅创建、移动和删除测试书签，不操作个人 Chrome 配置。浏览器测试覆盖新标签页替换、书签栏多层菜单和溢出、拖放归档及失败处理、原生书签事件、归档和撤回、打开链接不完成、标题安全、空列表、读取失败恢复，以及浅色/深色/窄窗口布局。

测试截图保存在 `artifacts/`。
